02 · 해결 방법

사진 한 장, 도장 찍기 전 3분

필요한 건 계약서 사진 한 장. 회원가입 없이, 도장 찍기 전 3분이면 충분해요.

기존 방법✓ 안부
수도권·전세사기 중심지방 대학가 월세 원룸 특화
누구에게나 같은 체크리스트내 계약서를 AI가 직접 읽음
계약 뒤에 알게 됨도장 찍기 전, 현장에서 바로
퇴실 분쟁까지 못 잡음원상복구·수리비 특약까지 확인
  1. 1계약서 사진 찍기회원가입 없이 바로 시작. 현장에서 계약서를 카메라로 찍으면 됩니다.
  2. 2AI가 읽고 위험 판정 보증금 반환·원상복구·시설 수리 조항을 빨강·노랑·초록으로 표시합니다.
  3. 3질문과 특약 받기그 자리에서 중개사에게 물어볼 말과 넣어 달라고 요청할 특약 문장을 만들어 줍니다.
  4. +서류까지 넣으면등기부·확정일자로 이중계약·깡통·신탁 위험도 확인합니다.

계약서마다 말이 다르니까

같은 '원상복구'도 계약서마다 문장이 달라 정해진 체크리스트로는 못 잡아요.

04 · 핵심 기능

찍고, 확인하고, 요청한다

도장 찍기 전 3분이면 충분합니다. 회원가입 없이 바로 시작해요.

  1. 1계약서 올리기

    카메라로 찍거나 앨범에서 여러 장을 한 번에. 샘플 계약서 6장으로 바로 체험할 수도 있어요.

  2. 2AI가 읽은 내용 확인

    보증금·기간·특약을 자동 추출. 틀린 곳만 눌러서 고치면 돼요. 등기부등본을 함께 올리면 이중계약·깡통 위험도 잡아줘요.

  3. 3위험 조항 판정

    3영역을 빨강·노랑·초록으로. 조항마다 "이렇게 해결해요"와 경산 실거래 시세 비교까지.

  4. 4질문·특약 받고 요청

    중개사에게 물어볼 질문 체크리스트와 추천 특약 복사. 그래도 안 되면 안부 파트너 전문가 상담.

05 · 특징·차별화 · 수익 구조

학생은 끝까지 무료

수익은 학생이 아닌 전문가·협약 부동산·학교가 만듭니다.

대학생점검 0원

계약서 점검·서류 대조 모두 무료. 상담은 원할 때만.

변호사·중개사 (안부 파트너)월 정액

실시간 상담에 참여하고 프로필 노출. 순서는 무작위·접속 중 순.

협약 중개사무소협약 광고료

안부 '안전 계약' 기준(추천 특약 반영·서류 공개)에 협약한 부동산을 앱에 노출. 정액 광고료.

대학·생활관·지자체연간 이용료

신입생·자취생에게 무료로 제공하는 학생 보호 도구로 도입.

수수료 0원

안부는 상담·계약마다 떼는 중개 수수료를 받지 않습니다. 상담료는 전문가에게 100% 직접 가고, 협약 부동산도 계약 건수와 상관없는 정액 광고료만 내는 광고형 구조예요.※ 안부는 법률 자문이 아닌 참고 정보를 제공하고, 법률 판단은 파트너 변호사가 합니다.

이번 대회아이디어 검증

심사위원·참가자 피드백으로 문제와 해결 방식 확인

대회 이후창업 아이디어 구체화

팀원들과 사업 모델·법적 검토를 더 다듬기
